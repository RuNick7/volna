# Визуальный язык Volna

Прототип: [`wave-service/volna/web`](../wave-service/volna/web). Android-приложение повторяет те же правила.

## Принципы

1. **Одна кнопка.** На главном экране в центре стоит большая круглая кнопка «Моя волна». Нажали — музыка пошла, больше ничего делать не нужно. Всё остальное вторично и визуально тише.
2. **Только чёрное и белое.** Фон `#000`, элементы `#FFF`. Цвет не используется вообще, даже обложки показываются в оттенках серого.
3. **Фон — топографическая карта, которая течёт волной.** Изолинии медленно накатывают сверху вниз, а под музыку колеблются сильнее.

## Цвета и прозрачность

| Токен | Значение | Где |
|---|---|---|
| `bg` | `#000000` | фон экрана |
| `fg` | `#FFFFFF` | текст, иконки, обводка кнопки, полоса прогресса |
| `muted` | белый 58 % | артист, подписи, «Дальше: …» |
| `faint` | белый 16 % | обводка второстепенных кнопок, дорожка прогресса |
| `veil` | чёрный 62 % | подложка кнопок поверх линий, чтобы текст читался |
| линии | белый 12 % (+10 % от громкости) | обычные изолинии |
| линии-акценты | белый 32 % (+30 % от громкости) | каждая пятая изолиния |

## Фон: изолинии-волны

* **Поле:** `f(x, y, t) = 0.0042·y − 0.06·t + A·(simplex(x, y, t) + 0.22·simplex₂ + 0.2·sin(...))`. Наклон по `y` укладывает изолинии в гряды, шум делает их похожими на рельеф, а сдвиг во времени заставляет гряды бесконечно накатывать.
* **Построение:** изолинии строятся методом marching squares с шагом уровней 0.17 по сетке 10–12 px.
* **Реакция на музыку:** громкость (RMS) увеличивает амплитуду `A` и скорость течения, а также делает линии ярче.
* **Производительность:** ~30 кадров в секунду; анимация на паузе, когда экран не виден. При `prefers-reduced-motion` картинка статичная.
* **Android:** тот же алгоритм на `Canvas` в Compose. Если понадобится больше плавности, можно перенести на AGSL-шейдер (Android 13+).

## Компоненты

| Компонент | Размер | Вид |
|---|---|---|
| Кнопка волны | 220 dp (не больше 56 % ширины) | круг с белой обводкой 1.5 dp и подложкой `veil`. Внутри — значок play/pause и обложка трека в ч/б с прозрачностью 42 %. Внешнее кольцо 1 dp пульсирует с громкостью, а пока волна загружается, вращается пунктиром |
| Название трека | 20–26 sp, semibold | одна строка, обрезается многоточием |
| Артист | 16 sp, `muted` | |
| «Почему этот трек» | 12 sp, `muted` | например, «В духе: …», «Разведка: …» или «Похоже на плейлист: …» |
| Прогресс | 2 dp | белая полоса на дорожке `faint`; по нажатию перематывает |
| Кнопки управления | 54 dp | круги с обводкой `faint`, линейные иконки 1.5 dp. Порядок: «не нравится», «нравится», «дальше»; нажатое «нравится» заливается белым |
| Характер волны | сегменты-«пилюли» | «Любимое · Баланс · Незнакомое»; выбранный сегмент — белый с чёрным текстом |
| «Дальше: …» | 13 sp, `muted` | следующий трек |
| Логотип | 15 sp | `volna` строчными, разрядка 0.38 em |

## Шрифт

Системный: SF Pro на Apple, Roboto на Android. Без внешних шрифтов, чтобы приложение работало офлайн.
