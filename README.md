# Volna

Свой музыкальный клиент для [Navidrome](https://www.navidrome.org/) в духе Яндекс Музыки. Главный экран — одна кнопка «Моя волна»: нажали, и дальше бесконечно идёт музыка, которую вы с высокой вероятностью дослушаете. Каждый пропуск сразу смещает веса, и волна уходит от того, что вам сейчас не заходит.

Звучание треков анализирует [AudioMuse-AI](https://github.com/NeptuneHub/AudioMuse-AI). Историю, лайки и прослушивания хранит Navidrome, поэтому они общие для всех клиентов.

## Что в репозитории

| Папка | Что это |
|---|---|
| [`wave-service/`](wave-service) | Сервис волны и библиотеки (Python, FastAPI) и веб-приложение к нему |
| [`android/`](android) | Android-приложение (Kotlin, Jetpack Compose, Media3): тот же API, фоновое воспроизведение |
| [`docs/architecture.md`](docs/architecture.md) | Архитектура: алгоритм волны, продолжение плейлистов, синхронизация, план |
| [`docs/design.md`](docs/design.md) | Визуальный язык: чёрный фон, белые элементы, топографические линии-волны |

Веб-приложение сделано «телефонным»: его можно открыть на смартфоне и добавить на главный экран. Android-приложение ходит в тот же API и умеет играть в фоне, из шторки и с экрана блокировки.

## Что есть в приложении

| Вкладка | Что внутри |
|---|---|
| **Главная** | Большая кнопка «Моя волна», она же экран «сейчас играет». Ниже полки: волна по вашим плейлистам, недавно слушали, давно не слушали, новое в библиотеке, часто слушаете, ваши артисты |
| **Поиск** | По трекам, альбомам, артистам и плейлистам всей библиотеки |
| **Коллекция** | Мне нравится, плейлисты, альбомы (сортировки: А–Я, новые, недавно слушали, часто, по году, любимые), артисты, недавно слушали. Страницы альбома, артиста и плейлиста: «Слушать», «Перемешать», «Волна по…», ★ |
| **Настройки** | По категориям, как в Tempus и Symfonium: Сервер · Моя волна · Воспроизведение · Интерфейс · Библиотека и вкус · О приложении |

Мини-плеер виден на всех вкладках, кроме главной. Когда альбом или плейлист заканчивается, музыка не останавливается: дальше идёт волна, похожая на весь список целиком.

## Быстрый старт: демо без сервера

В демо-режиме вместо Navidrome и AudioMuse работает синтетическая библиотека: 640 треков, 8 жанров, сгенерированный звук. Этого хватает, чтобы потрогать всё приложение.

```bash
cd wave-service
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/python -m volna --demo
```

Откройте <http://127.0.0.1:8765> и нажмите на круг.

Горячие клавиши: пробел — пауза, `→` — дальше, `←` — назад, `L` — нравится, `D` — не нравится, `S` — встряхнуть волну, `/` — поиск.

## Подключение своего Navidrome

1. Запустите сервис без `--demo`: `.venv/bin/python -m volna`.
2. Откройте **Настройки → Сервер**, впишите адрес Navidrome, логин и пароль, а для волны — адрес AudioMuse и API-токен **или** логин и пароль его веб-интерфейса.
3. Нажмите **«Проверить»**, затем **«Подключиться»**. Библиотека синхронизируется в фоне, прогресс виден там же.

Сервис переключается на ваш сервер без перезапуска и запоминает его.

Сразу после подключения сервис собирает профиль вкуса и в фоне один раз загружает в кэш векторы и признаки всей библиотеки. Для 12 тысяч треков это занимает несколько минут, прогресс виден в `GET /api/server` (`warm`). Волна работает и во время прогрева, просто первые порции собираются медленнее. Порции дозаполняются в фоне с запасом в 6 треков, поэтому «дальше» и «назад» срабатывают мгновенно. История каждого сервера хранится в отдельном файле `data/server-*.db`, так что демо и настоящая библиотека не смешиваются. Пароль и токен лежат только на компьютере с сервисом и никогда не возвращаются в интерфейс.

Без AudioMuse работают библиотека, поиск и плеер. Для волны нужно, чтобы AudioMuse уже проанализировал библиотеку: треки без анализа в волну не попадают. Можно по-прежнему задать сервер через `.env` (см. [`.env.example`](wave-service/.env.example)).

### Слушать с телефона

```bash
VOLNA_HOST=0.0.0.0 .venv/bin/python -m volna
```

Затем откройте на телефоне `http://<IP-компьютера>:8765` и через меню браузера добавьте страницу на главный экран: она откроется как отдельное приложение, без адресной строки.

> В прототипе нет авторизации, поэтому открывайте его только в домашней сети и не публикуйте порт в интернет.

## Android-приложение

Готовый APK лежит в [релизах](https://github.com/RuNick7/volna/releases). Приложение не хранит ни Navidrome, ни AudioMuse: оно ходит в сервис Volna, который работает на компьютере.

**На телефоне.** Запустите сервис с `VOLNA_HOST=0.0.0.0` (см. выше), поставьте APK (Android попросит разрешить установку из этого источника) и в **Настройки → Сервис Volna** впишите `http://<IP-компьютера>:8765`. Телефон и компьютер должны быть в одной сети.

**В эмуляторе на macOS.** Нужна Android Studio. Откройте папку `android/`, создайте эмулятор в Device Manager и нажмите Run, либо из терминала:

```bash
cd android
JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew installDebug
```

В эмуляторе адрес по умолчанию `http://10.0.2.2:8765` уже указывает на компьютер, сервис можно запускать как обычно.

Собрать APK самому: `./gradlew assembleRelease`, файл появится в `app/build/outputs/apk/release/`. Пока он подписан отладочным ключом, этого достаточно для установки на свой телефон.

## Из чего складывается вкус

Раз в 6 часов сервис синхронизирует всю библиотеку Navidrome. Это история и отметки, общие для всех клиентов: веб-интерфейса Navidrome, других плееров и самого Volna.

| Сигнал | Откуда | Что даёт |
|---|---|---|
| Сколько раз и когда играл каждый трек | Navidrome, `playCount` и `played` | вес трека `log(1 + прослушивания)`, затухает с полупериодом 120 дней; плюс «дослушивания» артиста |
| ★ трека, оценка 1–5 | Navidrome | ★ даёт +3; 5★ +3, 4★ +1.5, 2★ −1; 1★ — трек больше не звучит |
| ★ альбома, оценка альбома | Navidrome | +1 каждому треку альбома, альбом считается любимым; 1★ — альбом не звучит |
| ★ артиста, оценка артиста | Navidrome | +0.6 пятнадцати самым слушаемым трекам артиста, артист считается любимым; 1★ — артист не звучит |
| Ваши плейлисты | Navidrome | +0.8 каждому треку, затухает с давностью изменения плейлиста |
| Дослушал, пропустил (и на какой секунде), лайк, «не нравится» | события Volna — в волне, альбоме, плейлисте, поиске | веса треков, статистика артистов и альбомов, успех кластеров вкуса по времени суток и будням/выходным |

### Как волна реагирует на пропуски

| Что вы сделали | Что меняется сразу | Что меняется надолго |
|---|---|---|
| Дослушали (≥ 80 %) | вектор сессии сдвигается к треку, кластер чуть усиливается | +1 к весу трека, плюс артисту и альбому, успех кластера в это время |
| Пропустили до 30 с или до 25 % трека | вес кластера ×0.6, из очереди убираются похожие треки и тот же артист, вектор сессии отталкивается | −1.5 к весу трека, минус артисту и альбому; после двух ранних пропусков трек «отдыхает» |
| Два ранних пропуска подряд | волна переключается на другой кластер вкуса | — |
| Пропустили позже | вес кластера ×0.85 | −0.4 к весу трека |
| «Не нравится» | как ранний пропуск, только сильнее | 1★ в Navidrome, трек больше не звучит |
| «Нравится» | кластер и вектор сессии заметно усиливаются | ★ в Navidrome, +3 к весу трека |

Что система уже узнала, видно в настройках, в блоке «Ваш вкус»: кого вы дослушиваете, кого пропускаете и из какого источника треки заходят лучше.

## Настройки волны

Настройки сделаны по образцу яндексовских и открываются кнопкой под главным кругом. Музыка при смене настроек не прерывается: пересобирается только очередь.

| Настройка | Варианты | Как работает |
|---|---|---|
| Характер | Любимое · Баланс · Незнакомое · Забытое | доля знакомого и нового. «Забытое» — отмеченное и любимое, что давно не звучало (аналог яндексовского «Тайника»); вместо «Популярного», которое для одной домашней библиотеки почти бессмысленно |
| Настроение | Бодрое · Весёлое · Спокойное · Грустное | цели по энергии, темпу и шкалам настроения AudioMuse |
| Занятие | Просыпаюсь · В дороге · Работаю · Тренируюсь · Засыпаю | то же, с другими целями |
| Без слов | вкл/выкл | предпочтение треков с тегом `instrumental` из MusiCNN |
| Смелость подбора | 0.1–1.5 | температура выдачи AudioMuse и доля разведки в другие кластеры вкуса |
| Разнообразие | 0–100 % | насколько порция не должна повторять одно звучание и как быстро кластер «приедается» |
| Не повторять треки | 0–60 дней | окно, в течение которого недавно игравшее не возвращается |
| Время суток и выходные | вкл/выкл | учитывать ли, что утром в будни заходит одно, а вечером в субботу — другое |
| Встряхнуть волну | кнопка или `S` | уйти от текущего звучания и пару порций смелее исследовать вкус |

## Волна по треку, продолжение плейлиста, плейлист по песне

Всё это — та же личная волна, только **смещённая к источнику**: треку, альбому, артисту, плейлисту или только что закончившемуся списку.

* **Доля похожего.** Часть каждой порции ищется рядом с источником, остальное — ваш вкус, подтянутый в его сторону. Долю задаёт настройка «Волна по треку и плейлисту»: по умолчанию 65 %.
* **Части источника по очереди.** У плейлиста из двух жанров звучат оба, пропорционально их размеру.
* **Стартовое направление.** Вектор сессии стартует от источника, близость к нему добавляет очки.
* **Пропуски ослабляют смещение.** Если пропускаете похожее на источник, смещение слабеет на ходу, а пропущенная часть плейлиста звучит реже.

Где это в интерфейсе:

* **«⋯» у любого трека и у текущего на главной**: «Моя волна по треку» и «Собрать плейлист по треку».
* **Подборка по треку.** Это смещённая волна, собранная заранее: 15, 25 или 50 треков, первым идёт сам трек. Смещение сильнее (85 %), разрешены недавно игравшие треки. Подборку можно сразу слушать, пересобрать или **сохранить плейлистом в Navidrome** — он появится во всех клиентах.
* **На странице артиста** — «Волна по артисту» и «Плейлист» по артисту; у альбома и плейлиста — «Волна».
* **Конец альбома или плейлиста.** Музыка продолжается волной, смещённой ко всему списку.

Подробнее об алгоритме — в [docs/architecture.md](docs/architecture.md) и в docstring-ах [`engine.py`](wave-service/volna/engine.py).

## Проверка

```bash
cd wave-service
.venv/bin/python -m pytest
.venv/bin/python scripts/simulate.py
```

Симуляция гоняет виртуального слушателя по демо-библиотеке:

* **Волна держит около 75 % дослушанного** (максимум для этого слушателя около 80 %), а разлюбленный жанр почти не звучит.
* **Если слушатель разлюбил жанр,** который в истории был любимым, его доля падает с 14 % в первых 10 треках до 4 % в следующих 20 — прямо в первой же сессии.
* **Продолжение плейлиста из двух жанров** на 95 % остаётся в жанрах плейлиста и держит баланс между ними 65 %, хотя часть треков — из вашего вкуса. У «радио по последней песне» баланс 0 %: оно целиком уходит в жанр последнего трека.
* **Волна по треку из жанра, которого нет во вкусе,** ставит похожего на трек 57 % при смещении 0.35, 76 % при 0.65 и 95 % при 0.9. Остальное — любимые жанры. Обычная волна этот жанр не включает вообще.
* **Настройки меняют звучание.** Средняя энергия: «Спокойное» — 0.20, «Бодрое» — 0.70, без настроек — 0.41. «Без слов» поднимает долю инструментального до 95 %. Новых треков: «Любимое» — 25 %, «Незнакомое» — 95 %.

## API

| Метод | Что делает |
|---|---|
| `POST /api/wave/start` `{settings?, seed?, device?}` | запустить волну; `seed: {type: track\|album\|artist\|playlist, id}` — волна, смещённая к элементу |
| `POST /api/wave/{id}/advance` `{track_id, outcome, position, duration}` | трек закончился (`complete`), пропущен (`skip`), «не нравится» (`dislike`) или не играет (`error`); в ответ — следующий трек |
| `POST /api/wave/{id}/like` `{track_id, liked}` | лайк текущего трека в волне (звезда в Navidrome и усиление кластера) |
| `POST /api/wave/{id}/settings` `{…}` | поменять настройки на ходу; они же сохраняются по умолчанию |
| `POST /api/wave/{id}/shake` | встряхнуть волну |
| `GET /api/wave/{id}/debug` | как сместились веса кластеров в этой сессии |
| `GET`/`PUT /api/settings` | сохранённые настройки и допустимые значения |
| `POST /api/continue` `{track_ids, title}` | список закончился — волна, смещённая ко всему списку |
| `POST /api/mix` `{seed, size}` | плейлист по треку, альбому, артисту или плейлисту |
| `POST /api/playlists` `{name, track_ids}` | сохранить плейлист в Navidrome |
| `POST /api/events` `{track_id, outcome, position, duration, context_type, context_id}` | прослушивание вне волны (альбом, плейлист, поиск) — тоже учит вкус |
| `POST /api/like` `{type: track\|album\|artist, id, liked}` | лайк трека, альбома или артиста |
| `GET /api/taste` | «Ваш вкус»: кластеры, любимые и пропускаемые артисты, дослушиваемость по источникам |
| `GET /api/stream/{id}`, `GET /api/cover/{id}` | аудио и обложка через сервис (логин Navidrome не уходит в браузер) |
| `GET /api/home` | полки главной |
| `GET /api/library`, `/api/library/{albums,artists,playlists,liked,recent}` | коллекция; у альбомов и артистов параметр `sort` |
| `GET /api/album/{id}`, `/api/artist/{id}`, `/api/playlist/{id}` | страницы альбома, артиста, плейлиста |
| `GET /api/search?q=` | поиск по библиотеке |
| `POST /api/library/sync` | синхронизировать библиотеку сейчас |
| `GET /api/server`, `POST /api/server/test`, `PUT /api/server`, `DELETE /api/server` | подключение к Navidrome и AudioMuse: статус, проверка, сохранение, возврат к демо |
| `GET`/`PUT /api/preferences` | качество потока, продолжать ли похожим после альбома или плейлиста |
