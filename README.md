# Volna

Свой музыкальный клиент для [Navidrome](https://www.navidrome.org/) в духе Яндекс Музыки. Главный экран — одна кнопка «Моя волна»: нажали, и дальше бесконечно идёт музыка, которую вы с высокой вероятностью дослушаете. Каждый пропуск сразу смещает веса, и волна уходит от того, что вам сейчас не заходит.

Звучание треков анализирует [AudioMuse-AI](https://github.com/NeptuneHub/AudioMuse-AI). Историю, лайки и прослушивания хранит Navidrome, поэтому они общие для всех клиентов.

## Что в репозитории

| Папка | Что это |
|---|---|
| [`wave-service/`](wave-service) | Прототип сервиса волны (Python, FastAPI) и веб-плеер к нему |
| [`docs/architecture.md`](docs/architecture.md) | Архитектура: алгоритм волны, продолжение плейлистов, синхронизация, план |
| [`docs/design.md`](docs/design.md) | Визуальный язык: чёрный фон, белые элементы, топографические линии-волны |

Android-приложение — следующий этап. Оно будет ходить в тот же API, что и веб-плеер.

## Быстрый старт: демо без сервера

В демо-режиме вместо Navidrome и AudioMuse работает синтетическая библиотека (около 600 треков, 8 жанров, сгенерированный звук). Этого хватает, чтобы потрогать волну и проверить алгоритм.

```bash
cd wave-service
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/python -m volna --demo
```

Откройте <http://127.0.0.1:8765> и нажмите на круг.

Управление: пробел — пауза, `→` — дальше, `L` — нравится, `D` — не нравится.

## С вашим Navidrome и AudioMuse

```bash
cd wave-service
cp .env.example .env    # впишите адреса, логин Navidrome и API_TOKEN AudioMuse
.venv/bin/python -m volna
```

Нужно, чтобы AudioMuse уже проанализировал библиотеку: треки без анализа в волну не попадают. Проверка связи: <http://127.0.0.1:8765/api/health>.

> В прототипе нет авторизации. Чтобы слушать с телефона, задайте `VOLNA_HOST=0.0.0.0` и открывайте только в домашней сети, не публикуйте порт в интернет.

## Как волна учится на пропусках

| Что вы сделали | Что меняется сразу | Что меняется надолго |
|---|---|---|
| Дослушали (≥ 80 %) | вектор сессии сдвигается к треку, кластер чуть усиливается | +1 к весу трека, успех кластера в это время суток |
| Пропустили до 30 с или до 25 % трека | вес кластера ×0.6, из очереди убираются похожие треки и тот же артист, вектор сессии отталкивается | −1.5 к весу трека, провал кластера, минус артисту; после двух ранних пропусков трек «отдыхает» |
| Два ранних пропуска подряд | волна переключается на другой кластер вкуса | — |
| Пропустили позже | вес кластера ×0.85 | −0.4 к весу трека |
| «Не нравится» | как ранний пропуск, только сильнее | 1★ в Navidrome, трек больше не звучит |
| «Нравится» | кластер и вектор сессии заметно усиливаются | ★ в Navidrome, +3 к весу трека |

Подробнее об алгоритме — в [docs/architecture.md](docs/architecture.md) и в docstring-ах [`engine.py`](wave-service/volna/engine.py).

## Проверка

```bash
cd wave-service
.venv/bin/python -m pytest
.venv/bin/python scripts/simulate.py
```

Симуляция гоняет виртуального слушателя по демо-библиотеке:

* **Волна держит около 78 % дослушанного** (максимум для этого слушателя около 80 %), а разлюбленный жанр почти не звучит.
* **Если слушатель разлюбил жанр,** который в истории был любимым, его доля падает с 14 % в первых 10 треках до 4 % в следующих 20 — прямо в первой же сессии.
* **Продолжение плейлиста из двух жанров** держит баланс жанров 94 %, а «радио по последней песне» — 0 %: оно целиком уходит в жанр последнего трека.

## API

| Метод | Что делает |
|---|---|
| `POST /api/wave/start` `{mode}` | запустить волну; режимы `favorite`, `balanced`, `discover` |
| `POST /api/wave/{id}/advance` `{track_id, outcome, position, duration}` | трек закончился (`complete`), пропущен (`skip`), «не нравится» (`dislike`) или не играет (`error`); в ответ — следующий трек |
| `POST /api/wave/{id}/like` `{track_id, liked}` | лайк или снятие лайка (синхронизируется со звёздами Navidrome) |
| `POST /api/wave/{id}/mode` `{mode}` | сменить характер волны, не прерывая текущий трек |
| `GET /api/wave/{id}/debug` | как сместились веса кластеров в этой сессии |
| `POST /api/continue` `{track_ids}` | продолжить плейлист похожим на весь плейлист |
| `GET /api/profile` | кластеры вкуса |
| `GET /api/stream/{id}`, `GET /api/cover/{id}` | аудио и обложка через сервис (логин Navidrome не уходит в браузер) |
